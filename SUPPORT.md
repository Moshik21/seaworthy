# Getting help

Seaworthy is pre-1.0 hobby tooling, maintained on a best-effort basis. Help comes through
the repository's GitHub issues (the Issues tab); there is no other support channel and no promised response time.

Before asking, these usually answer the question:

- [README.md](README.md) for what this project does and how to run it.
- [docs/troubleshooting.md](docs/troubleshooting.md) for real messages and what to do about them.
- [docs/safety.md](docs/safety.md) for what is refused, what is written, and the exit codes.

## Bugs, questions and check requests

Open an issue (the templates in `.github/ISSUE_TEMPLATE` cover a bug and a check request). Include:

- the Seaworthy version (`seaworthy --version`) and how you installed it (checkout, zip or wheel);
- your operating system and Python version (`python3 --version`);
- the exact command you ran;
- the plain output, as text (`--json` if you can), not a screenshot;
- what you expected instead.

Remove anything private first: no tokens, keys, passwords or other secrets, and no names or addresses you would not
post publicly. Reports are scrubbed of credential patterns, but check before you paste.

## Security problems

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).
